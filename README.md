# DACAR MARKET — POS & Inventory Management System 🚗✨

Современная система автоматизации розничной торговли и складского учета для детейлинг-маркета **DACAR**.

## 🚀 Основные возможности

- 🛒 **Кассовый POS-терминал**:
  - Быстрый поиск по названию, артикулу и штрихкоду
  - Поддержка сканера штрихкодов
  - Оплата наличными (с расчетом сдачи и быстрыми купюрами), картой, Kaspi QR
  - Печать термочеков (58мм / 80мм)
  - Полная адаптация под мобильные устройства (iOS Safari / Android)
- 📦 **Каталог и Складской учет**:
  - Управление товарами, категориями и поставщиками
  - Учет остатков, себестоимости и розничных цен
  - Уведомления о минимальных остатках
- 📊 **Аналитика и Отчеты**:
  - Выручка, прибыль, средний чек
  - Динамика продаж по дням и категориям
  - Топ продаваемых товаров
- 👥 **Управление персоналом**:
  - Роли: Администратор, Кассир, Менеджер склада
  - Разграничение прав доступа и журнал действий

## 🛠️ Стек технологий

- **Backend**: Python 3, Django 5, Django REST Framework
- **Database**: SQLite (для разработки) / PostgreSQL (для продакшена)
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+), FontAwesome 6, Chart.js

## 💻 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/kazban0v/Dacar.git
cd Dacar

# Создать и активировать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # macOS / Linux
# .venv\Scripts\activate   # Windows

# Установить зависимости
pip install -r requirements.txt

# Применить миграции
python manage.py migrate

# Запустить сервер разработки
python manage.py runserver
```
